# Project Blueberry

Autonomous maze escape robot built on the Fenrir robotic platform using ROS2.

## Features

- Corridor navigation using LiDAR and IMU
- Intersection detection
- ArUco marker recognition
- Autonomous turning and wall following
- State-machine based control

## Technologies

- ROS2
- C++
- LiDAR
- IMU
- OpenCV ArUco
